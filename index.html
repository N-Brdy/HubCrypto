    Comment fonctionne ce tableau de bord ?

    La page interroge directement deux API publiques avec fetch(), puis met à jour l'affichage toutes les 60 secondes. Aucun serveur n'est nécessaire : tout tourne dans votre navigateur.

    • Duino-Coin : lecture de balance sur server.duinocoin.com/balances/Nono_coin.
    • NerdMiner : lecture du hashrate, de workersCount et de la meilleure difficulté sur public-pool.io:4000. Le hashrate est converti de H/s en KH/s. S'il n'est pas fourni globalement, il est calculé en additionnant celui de chaque worker.
    • Erreurs : « Chargement... » au démarrage, « Erreur réseau » si l'API ne répond pas (délai max. 15 s). Chaque widget échoue indépendamment.
    Historique et graphiques

    À chaque actualisation réussie, une mesure est enregistrée dans le localStorage de votre navigateur (max. 500 points par widget, soit environ 8 h). Les courbes et le « gain depuis le début » se basent sur cet historique. Il reste privé et local ; vous pouvez l'effacer avec le bouton dédié.

    Alertes de surveillance (fonctionnalité clé)

    Un mineur qui s'arrête en silence fait perdre du temps de calcul. Le tableau de bord détecte donc :

    • une API injoignable 2 fois de suite ;
    • une baisse du nombre de workers actifs ;
    • un hashrate sous le seuil que vous définissez (0 = désactivé) ;
    • le retour à la normale.

    Chaque alerte est consignée dans le journal et peut déclencher une notification navigateur et un bip sonore. La page doit rester ouverte dans un onglet.

    Bon à savoir

    Si le navigateur bloque une requête (CORS) lorsque la page est ouverte en file://, essayez un petit serveur local (npx serve). Le minage solo Bitcoin avec un NerdMiner relève de la loterie : l'indicateur « best diff » montre seulement à quel point vous vous êtes approché d'un bloc.

    Comptes et sécurité

    Le compte est créé et stocké uniquement dans votre navigateur (il n'existe aucun serveur). Votre mot de passe sert à dériver une clé (PBKDF2, 600 000 itérations) qui chiffre vos clés en AES-GCM : un mauvais mot de passe ne peut donc pas les déchiffrer. Le mot de passe n'est jamais stocké. Chaque compte a son propre historique et ses propres réglages.

    • Les comptes ne sont pas partagés entre navigateurs ou appareils.
    • Mot de passe oublié = clés à ressaisir sur un nouveau compte (il n'y a pas de récupération).
    • Pour que le chiffrement soit disponible, ouvrez la page via https://, localhost ou file://.
